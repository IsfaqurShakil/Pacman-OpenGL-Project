# Pacman OpenGL Project

This is a 2D Pacman game developed using C++ with OpenGL and GLUT for CSE 426 Computer Graphics Lab.

## Features
- 23x21 maze
- Pacman movement using arrow keys
- Four ghosts
- Score, lives, level, and timer
- Power pellet mode
- Menu, help, pause, game over, and win screens
- Bresenham line, DDA line, and Midpoint circle drawing algorithms

## Controls
- Arrow Keys: Move Pacman
- P: Pause / Resume
- H: Help
- ESC: Back to menu
- R: Replay
- Q: Quit
